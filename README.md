# Blog Application

A blog application built using Next.js and ASP.NET Core Web API.

## Features

* User login
* Create, read, update and delete posts
* Save posts as drafts
* Publish drafts
* Upload images, videos, audio and other files

## Tech Stack

* Next.js
* ASP.NET Core Web API
* C#
* Database

## Goal

To learn and understand the complete flow of a web application using Next.js and .NET.
